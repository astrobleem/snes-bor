The generic costmove compiler follows pinned BOR 4086 check_costmove,
check_energy and ent_unlink. Its controls and 128 entity combo tails require
an exclusive caller payload lease; it does not silently reserve production RAM.

Begin preserves the source fs/nospecial gates, HP-first eligibility, MP-or-HP
debit, cost bypass, attacking/action flags, velocity and combo reset, and real
peer/self unlink order. Signed debit overflow is rejected before mutation.
Animation initialization is real and returns pending frame-zero work. The caller
must issue StartFrame, execute the native script/effects owner, and acknowledge
that completed animation before Finish can publish success. Neither service
silently acknowledges a callback.

The verbatim pinned C authority compares 2304 cases and 184320 state bytes.
The native prefix proof compares 195 cases, including 14 admission/overflow
guards, over actual source entity stores and the full 16x168 animation cache.
Its private immutable energy descriptor variants are explicitly instrumented.

The callback continuation proofs use actual source energy tables and compiled
VM callbacks, real frame/effect owners and real animation acknowledgment.
He_ManB freespecial4 completes in both directions with its authored zero cost.
He_Man special completes in both directions with MP 100 -> 90 and HP 150 retained.
The external sound service remains instrumented. Their payload at 7FA000 is an
explicit isolated retired-producer fixture lease; production canvas ownership
was certified separately and has not yet been bound to the gameplay dispatcher.

This is not full player_think, combat, effect presentation or MOTU Demo completion.
No source color reduction or PCM copies are applied.

Combo selection has a distinct pure energy query: valid current-model animation,
then MP first, and HP only if MP fails. It shares costmove's canonical field
capture and immutable table validation. The native proof compares 195 cases,
exact short-circuit query order, and zero actor-byte mutation. Link validity and
signed debit overflow belong to the later mutating costmove; they do not turn
this pure eligibility query into an actor mutation preflight.

The compiler-owned controller address plan consumes 5424 of the 6400 leased
bytes, leaving 976. It includes input histories, entity movetime, combo tails,
input binding/snapshot/sequence controls, costmove and command continuations.
It reserves no extra animhits array: shared source animation hits already have
an initializer-owned canonical store. Layout generation alone grants no lease.

Canonical velocity is side +36/+40/+44. Auxiliary +0/+4 are authored frame
movex/movez, and auxiliary +8 is altbase. Costmove clears only horizontal side
velocity before ent_set_anim; vertical velocity and frame deltas remain intact
at that prefix boundary. Animation initialization owns any later delta reset.
The updated native proof seeds distinct nonzero values in both stores and
checks the real fields, correcting the earlier auxiliary-field binding.

Native entry tests set decimal mode before calling costmove and the pure energy
query. Binary arithmetic clears decimal internally and restores the caller flag.
