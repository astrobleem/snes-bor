# Separate source active palette identity

The pinned source stores `entity.map` as a restore index. A freeze attack assigns `entity.colourmap` through `model_get_colourmap` without changing that index. The `unfrozen` macro calls actual `ent_set_colourmap`, which clamps an invalid unsigned request to base and updates the restore index. A single shared index cannot preserve both identities.

The unchanged `checkdamageeffects`, palette lookup/application, `diff` and `inair` functions pass 3,072 pointer-identity cases. They include all 16 model declarations, authored frozen maps, a frozen-map value of -1 that preserves the current palette, other negative values that convert to unsigned and select base, repeated freeze/unfreeze state and invalid restore requests. Source palette vectors and asset-derived RGB555 hashes remain recorded in the requirements. No color-count reduction is used.

The native identity service passes 1,046 cases: birth, selection, read and restoration, all physical slots, all model palette counts, wide unsigned requests and stale guards. Birth overwrites an arbitrary old 12-byte row before exists publication; birth on a live entity rejects. It checks independent generation, physical identity, actual stored view token, hit-state lease, constructor/model pairing and active-map range before updates. Selection preserves the restore map; restoration updates it to the selected source map. Every case compares actor, palette, hit and CHR rows and CPU context. Bank 0 remains byte-identical to the repaired baseline.

The new 128-row registry occupies 1,536 bytes; controls occupy 64 bytes below the movement controls. Its proposed serialized CHR capacity is 46,336 bytes, reduced from 47,936. The 8bpp 896-tile conversion splits into 720 tiles (46,080 bytes) and 176 tiles (11,264 bytes); the 2bpp 512-tile job uses 8,192 bytes. Descriptors stay within the staging window. This identity proof does not execute those conversions or admit a live producer/IRQ/DMA lease.

The existing BODY restore-map field is uint16. Admitted `ent_set_colourmap` producers clamp to a map count no larger than 65,535, preserving that closed source domain. Direct wider map mutation is unadmitted; this component does not certify arbitrary 32-bit restore-map storage. The new active owner/map pair and independent generation live separately from that field.

The service is an isolated phase 8 proof. Production constructor hooks, model-transition reset, the full freeze callback, CGRAM/CHR palette presentation and the unified workspace owner remain unbound. An active owner inconsistent with the new source model fails explicitly. These results do not certify MOTU gameplay or Demo completion. No PCM copies were made. The [receipt](receipts/byor-motu-current-colourmap-native.json) records retained reports and observer hashes.
