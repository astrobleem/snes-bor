# Source hit prelude and block selection

The generic `SOURCE_EMPTY_ONDOATTACK_ZERO_GROUND` capability derives all 16
MOTU model identities from source. Their script descriptors admit animation
scripts only; every `ondoattack` instance is uninitialized. Their source
ground-missile flag is zero. Authored nonempty events, subclasses or a nonzero
ground flag reject this capability. Dynamic writers require another capability.

The unchanged pinned post-collision prefix and both actual empty event
dispatches pass 324 C authority cases. Owner roots, two owned projectiles,
ground/inair ordering and confirmation truth values are covered. `inair` is
instrumented in this authority; its arbitrary binary32 body is not certified.
The source restores its old global `self` only inside the confirmation branch.
In particular, a false confirmation retains the defender self. The native
capability requires the collision's actual nonzero confirmation and empty
events, so it does not invent a restore for that unsupported branch.

With the optional prelude enabled, the actual native ordered attack loop checks
the paired immutable B5SC/B4CO model programs, live initialized mask and absence
of clear/onkill entries. It resolves the target owner chain through the actual
source token resolver. Valid dead owners remain valid pointers; malformed or
cyclic owner graphs fail. Shared roots and two owned projectiles reject the
contact and continue the ordered scan without damage, block RNG, or hit-ID
publication.

An accepted contact suspends at the source `if(didhit)` body, with global self
on the defender and mandatory ticket `8112`. Hit controls +36..43 reuse the
completed gate/identity scratch to retain old self, didhit and marker B6A7.
Gate/identity reentry is forbidden while the call is pending. Pain/contact
controls keep cursor +56, target +58 and state +60; state 4 means the real
item/blocking/damage body is required. Retry validates the retained marker,
old-self token, target token and actual defender self. It does not repeat the
events, collision or attack-ID allocation. No response injection or world
acknowledgement API exists.

The repaired-ROM native matrix passes 794 cases over pool counts 1..128,
empty/far/hit scenes, both endpoint slots, ownership rejection, first-contact
suspension, retries and invalid leases. Actor and sibling rows, generation,
world phase, pending state and CPU context are observed. A focused repeat
checks the actual failure stages, avoiding a false guard proof caused by an
earlier target-generation failure. Bank 0 is byte-identical to the repaired
baseline; CHR capacity remains 47,936 bytes. The first FAIL, the superseded
789-case guard result and the failed suspension extension are retained. The
final receipt cites the corrected 794-case result and staged guard repeat.

`source_hit_block_4086.py` models the next ordered choice: passive block,
active block, counter, then damage. The unchanged pinned predicates pass
16,897 C cases with branch results, validanim/inair/rand32 call counts and
call order. Signed extremes and binary32 comparison conversions are covered.
These service bodies and the branch action bodies are instrumented. This is
not a native completed block or damage proof.

The derived `SOURCE_DEFAULT_BLOCK_PROPERTIES_NO_COUNTER` requirement covers
all 80 source animations. Model blockback/thold/blockpain and guard max are
zero; immutable uniform blockpower and blockthreshold are zero; counter frame
range defaults to -1/-1. Skeletor's authored BLOCK handle is 59, selected from
source role 13, rather than an actor-name special case. The eventual owner
must use the live mutable animation cache, actual rand32 stream and the
explicit Q16 inair adaptation, and capture the initial self defense threshold
before attack preparation. Nondefault properties/counters require another
capability.

Remaining work includes the item/block/damage bodies, nonself damage callbacks,
animation services, effects, followups, pause, pain timing, hit-ID publication,
post-loop sound/cost handling and production world integration. The foreign
profile is unregistered and real MOTU gameplay is unproven. No color reduction
has been applied.
