# Native source blocking branch selection

`SOURCE_DEFAULT_BLOCK_PROPERTIES_NO_COUNTER` derives all 16 model records,
80 animations and 31 attacks. This closed capability requires zero model
blockback/thold/blockpain and guard max, uniform immutable zero blockpower and
blockthreshold, disabled counter frames, no item attack, and zero juggle cost.
Other source requirements reject this capability. Actor names do not choose
the implementation. The mutable model cache selects source BLOCK role 13;
the inherited handle retains its immutable source frame count.

`HitBlock_Run` requires an actual accepted collision and hit prelude, with
defender global self and B6A7. It validates the world phase/time/generation,
captured attack cursor, actual paired factor rows and animation cache extent.
It reads the current direction, idling, attacking, blocking, frozen, link,
nopassiveblock and blockodds fields. The native inair predicate remains the
explicit Q16 adaptation; arbitrary binary32 equivalence is not claimed.

Under this capability, the pre-block item branch is absent and subtracting
zero juggle cost cannot change the current metric. The pure inair call for
that subtraction is eliminated. The actual source bomb flags change from
exact integer 1 to 2 before rand32. Rand32 is required only after the earlier
passive-block predicates pass, including when blockodds is zero. It uses the
existing source-world stream and exact recurrence, independently of CRT rand.

The selector returns `8113` for required passive block, `8114` for required
active block, or `8115` for required damage. Pain/contact state 5 retains the
chosen ticket at +62. Repeating the selector validates the pending context
and returns the same ticket without another random draw or bomb update.
It does not execute the selected action body, accept fabricated damage, or
acknowledge the world phase. The loop's earlier state-4 pending provider must
transfer ownership to this selector; it cannot poll an action-body ticket.

The isolated native matrix passes 175 cases. The nominal matrix has 162
cases over three physical actor slots, absent/inherited BLOCK handles,
passive/active branches, same direction, airborne/frozen/linked/busy targets,
negative attacking state, zero block odds and three source random seeds.
Every nominal case retries the chosen service. Twelve guards reject damaged
factor leases/vectors, cache descriptors/handles, attack cursors, typed
directions and unavailable random state. A control proves unavailable random
state is harmless when the branch does not reach rand32. Protected actors,
siblings, factors and cache rows are observed, with only the source bomb
changes and earlier attack-ID allocation admitted. Full seed, call-count,
busy, global-self, phase/pending and CPU records are compared.

The first proof failed because the original collision fixture only overlapped
on one facing direction. Mirroring produced a source-correct miss, rather
than an admitted target. The positioned repeat exposed an unresolved observer
placeholder. The corrected observer then found a real integration error:
the completed collision query descriptor must be returned to idle before a
fresh query; sticky status 3 still fails. All failed artifacts are retained.
The final native proof preserves bank 0 byte-for-byte and uses the existing
47,936-byte CHR capacity. No PCM is copied.

The unchanged C blocking predicates also pass 16,897 branch/call-order cases.
Their service and action bodies remain instrumented. Native scalar selection
does not certify completed damage, block frame-zero services, flash spawning,
hit-ID/pain-time publication, final sound/cost, or the continuation after a
failed damage callback. Those owners, the production world integration and
actual MOTU gameplay remain required. The foreign profile is unregistered.
No color reduction has been applied.
