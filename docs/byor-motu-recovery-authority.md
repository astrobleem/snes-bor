# Source recovery authority and persistent fields

The pinned BOR 4086 common_lie, set_rise and common_rise functions match the
explicit recovery mutation plans across 1,560 literal C cases. Child services are
instrumented separately. The cases cover dying policies, KO map timing, deadlines,
altitude equality, vertical velocity, missing rise animations, invincibility signs
and distinct target/global-self objects. The source set_rise clears target velocity
X but global self velocity Y/Z; this asymmetry is preserved. INT_MIN ABS behavior
is outside the admitted domain.

All 16 source models produce an immutable recovery policy descriptor. They have
zero fall-death, no-die-blink and KO-map policy, and zero juggle maximum. The
He_Man models declare riseinv 1, which the source loader multiplies by GAME_SPEED
200 before converting to int. Their compiled riseinv is 200 ticks, not one tick.
Live model property changes require an additional owner.

Blink and invincibility time require 2,048 persistent bytes for 128 actors, plus
64 control bytes. These rows are below the existing scoped callback snapshots;
palette, movement, pain, hit and pending-jump addresses stay fixed. Existing hit
contact rows remain the juggle-current owner. The CHR workspace shrinks from
27,136 to 25,024 bytes. The same 896 high and 512 low tiles are described by
four transfers of 24,576, 24,576, 8,192 and 8,192 bytes. No graphics bytes are
discarded. All producers must adopt that boundary before production activation.

The native storage owner passes 1,058 cases across every physical slot: actual
birth clears both fields, reads and writes preserve full words, blink clearing
retains invincibility time, and invalid leases preserve every row. CPU context and
decimal mode are restored. Bank 0 is unchanged. An earlier fixture supplied the
previous, oversized staging capacity and correctly failed at case 512; its FAIL
report is retained.

This does not bind common_lie/rise to gameplay, constructor publication, model
copying, continuous graphics/audio ownership, or a production memory lease.
All 17 protected tracked files remain unchanged. No PCM copies or color reduction
are applied. [Bounded receipt](receipts/byor-motu-recovery-authority-native.json).
