# Model services retain palette identity across nested idle

The synchronized model-service pipeline now has an isolated join with the independent active-palette reset, 27,136-byte CHR staging contract, scoped frame push/pop and guarded water dispatch. Both colour services use the derived model palette capability. No actor-name branch selects the new behavior.

The native proof passed 52 synchronized-transition cases and 40 authored frame-event/nested-idle cases. Observers compare the active owner/map rows, unchanged hit identities and CHR staging alongside the original model, entity, variable and CPU scopes. The real native services acknowledge their transitions; the observer writes no acknowledgements. The nested route executes the actual parent animation callback, weapon frame event, nested idle frame zero and frame completion. Bank 0 remains byte-identical. The [receipt](receipts/byor-motu-model-current-pipeline.json) records source-derived bundle and native artifact hashes.

Current-palette emission accepts an explicit smaller staging budget while retaining the canonical persistent row addresses. Its existing default emits identical assembly. Every producer must share the selected budget before production admission.

These prototype runs peaked at 667,268 and 1,582,510 master clocks respectively, including interrupts. They do not establish a complete tick budget. The unsynchronized model-transition service 4 needed by a different-model `dropweapon` call remains unbound; synchronized weapon-frame transitions and their later nested idle are separate source operations. Full combat callback completion, production resource ownership, foreign profile admission and MOTU Demo completion remain unproven. No color reduction was applied; no PCM copies were made.
