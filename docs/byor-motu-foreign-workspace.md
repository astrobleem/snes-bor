The exclusive foreign canvas can lease 6400 bytes at 7FA000 after retiring the
original frontpanel and water owners. This opt-in workspace is distinct from
the SA-1 execution lease and from the live source VM slots at 7FC000.

SourceForeignWork_Init requires a nonzero generation, the actual canvas owner,
the B672 water-retirement contract, inactive frontpanel producers, ROM raster
targets, and all eight legacy DMA descriptors inactive. It clears the arena
before publishing B671. Check validates generation and owner, rejecting active
DMA source ranges that overlap the arena. Unrelated transfers remain permitted.
Cold initialization revokes the lease. Code resides in bank 51; bank zero does
not grow. Status is diagnostic; a failed check does not mutate the payload or
silently revoke an existing generation.

The arena includes original water state as well as frontpanel cache arrays.
Clearing only the frontpanel flags is insufficient: the original water NMI hook
would interpret arbitrary leased bytes as live water state. The isolated
canvas handoff explicitly retires that hook before publishing B672. A future
production owner must make the same retirement concrete and compose authored
water through its own source presentation capability.

Native proof: m4_cooperative_source_graphics_native.py --hybrid-ppu
--foreign-workspace. The source bitmap is generated by the persistent SA-1
world, converted natively, then published by the real NMI/IRQ canvas path.
Initialization and 30 owner/generation/DMA checks pass with unchanged test
payloads. Four 256x224 fields have zero RGB555 mismatches; CGRAM and OAM traces
are exact and OBJ overflow is absent. No color reduction is applied.

This proves isolated arena ownership, not production foreign gameplay admission,
live camera binding, player control, or MOTU Demo completion. Costmove and player
input must relocate their state here before concurrent full VM callback tests.
