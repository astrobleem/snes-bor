# Ground continuation services

The generic compiler emitter connects canonical ground state to actual native
animation validity, the live empty-candidate search, single-series walk-family
selection and direct animation initialization. It requires the source's
max_walks limit to be one, matching the existing default walk owner and its
checked walkmode domain. Animation numbers come from the pinned source dialect
configuration; actor identities do not choose behavior.

The service owner publishes movement before item/animation services and captures
fresh actor fields after they return. Query requests use actual animation
resolution. Item requests prove the live TYPE_ITEM candidate set is empty;
matching candidates require the full source touch owner. This is a measured
short circuit, not an unconditional no-op pickup service.

The 32-byte controls contain B67E readiness and state at +2. Begin accepts state
0 or 2, captures the canonical snapshot and starts the ground continuation.
It returns A=0 when complete (state 2), or A=1 when a real frame callback is
required (state 3). The caller executes SourceAnimationInit StartFrame and the
actual frame/effect owner, then calls FinishFrame, which acknowledges that
frame through the actual animation owner and resumes ground execution.
Requests are serialized. Failure sets state 4 and carry.

Common idle is intentionally a separate required service: source ground calls
common_idle_anim, whose flag behavior differs from set_idle. A request for it
fails explicitly. TURN also requires a registered native action before its
snapshot wire value can be published. All authored MOTU models lack TURN; the
live validity query still determines the path. No missing service is silently
acknowledged.

The isolated callback proof uses native constructor state clearing, fresh model
copy, RUN tuple birth capture, authored SELECT completion, canonical ground
capture/publication and real WALK frame-zero execution. Its input and level
context and foreign root installation are instrumented. It does not prove the
full earlier player_think gates, production dispatcher, live graphics, stage
traversal or MOTU completion. Sound tickets remain the callback fixture's
explicit external service boundary.

No production assembly or bank 0 is changed. No color reduction is applied.
