# Native suicide with checked retirement

The pinned player_blink and suicide bodies pass 3,024 literal source cases.
Their children are instrumented for this authority comparison. Player_blink
sets blink before comparing the unsigned deadline. Suicide returns before the
deadline, then ORs the complete boss value into level completion and calls kill.

The native suicide owner joins that deadline/completion policy to actual
SourceRetirement4086 preflight and no-event mutation. It checks the canonical
self, generation, frame time, constructor and freeze state and requires the
scroller completion value to match the retirement role value. Preflight runs
before completion publication. Repeated calls complete without duplicate
retirement. The owner borrows existing common-action controls.

The join passes 162 cases, including deadline waits, nonboolean boss values,
physical actor mappings through slot 127, completion preservation and 18
rejections. Complete actor, relation, role and script-variable state is compared
with the literal kill authority. CPU context is preserved. Retirement failures
block clock commit. The first fixture correctly failed when its obsolete
retirement-slot injection was overwritten by the new owner; the fault now
injects an out-of-range owner slot and is rejected.

Initialized kill/clear callbacks and recursive minion children remain explicit
failures under the existing retirement contract. Actual check_ai dispatch,
player_die, production leases and MOTU gameplay are not certified. The peak
bounded call cost is 619,490 master clocks; this is a functional isolated proof,
not admission to a gameplay deadline. Bank 0 is unchanged; the width audit has
zero violations and all 17 protected hashes are intact. No color reduction or
PCM copies were made. [Receipt](receipts/byor-motu-suicide-native.json).
