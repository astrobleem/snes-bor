# Preserve caller controls across child frames

The existing continuation stack saves 528 bytes of frame state and a separate VM row. It omits the later palette, movement, pain, hit and foreign-controller controls. A child could overwrite a parent's palette contact and world phase even while the persistent actor rows remain correct.

The generic scoped-control stack saves 2,348 caller bytes in each of eight 2,368-byte rows. Its 64-byte descriptor and rows occupy 19,008 bytes at `426A00..42B43F`, below the existing palette controls. CHR staging becomes 27,136 bytes. The source-sized 896-tile 8bpp upload splits into 416, 416 and 64 tiles; the 512-tile 2bpp upload remains one job. These descriptors preserve source pixels and dimensions; every production producer still needs to adopt this boundary before the lease is enabled.

The saved regions contain four storage-service headers, 35 foreign control regions and the 52-byte world-tick context. Persistent actor palette, movement, pain and hit rows, player input history, entity controller fields, the attack-identity sequence and RNG remain live. Per-row identity and generation checks reject stale or occupied rows before copying. The actual frame owner preflights storage before suspending `self`, saves after native VM capture, and restores after its original frame/tail copies.

A native run passed 129 storage cases, including eight-level LIFO chains, guards, all compared bytes and CPU context. Every case directly invoked all seven retired water entry points and observed their retirement branches. The actual frame push/pop join passed 173 cases, including nested `self`, original admission guards, outstanding-continuation idle checks and clock inhibition. Bank 0 remains byte-identical. Peak observed costs were 158,480 master clocks for the storage fixture including seven water calls, and 210,112 for the frame owner. These costs include interrupts; they do not establish a complete gameplay tick budget. The [receipt](receipts/byor-motu-scoped-control-stack.json) records retained reports and hashes.

The earlier native run found writes to `7FB222..24` by the ordinary water NMI despite a published retirement marker. A marker alone did not retire its actual entry points. The private join now guards Reset, Begin, OamBegin, ApplyOamY, End, Nmi and ClearGuard. Either the published water-retirement marker or a live foreign lease blocks access; invalid lease requests do not revive the water owner. The ordinary branch executes a copy of the existing source water body. This is an isolated dispatcher join; the production retirement handoff and unified renderer/resource owner remain unbound.

The full constructor/native-pair route, model switching and MOTU gameplay still require integration. This proof does not admit the foreign profile or certify Demo completion. No color reduction was applied. No PCM copies were made.
