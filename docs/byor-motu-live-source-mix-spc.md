# Live source mixer and SPC transport

The native two-channel 1UP/death mixer and predictive BRR encoder now produce the stream while the production SPC consumer plays it in the same isolated ROM. The fixture publishes a monotonic count of completed BRR bytes. It starts after two 176-sample jobs (198 bytes), permits one prefill packet, and advances the producer watermark from the acknowledged transport cursor. A private wrapper verifies each packet's meaningful bytes before calling the existing host row filler. The SPC driver is unchanged.

The final ordinary and forced-conversion runs pass: 108 native jobs, 38,016 PCM bytes matching pinned BOR output, 10,692 BRR bytes matching the codec authority, 75 acknowledged packets, and all 1,188 DSP blocks in order. There are zero meaningful or padding mismatches, skipped/repeated blocks, fingerprint mismatches, observed consumer underruns, premature packet waits or clipping faults. Both final phase and active state match the source. The observer sees 105 nonfinal jobs after stream admission, followed by the final job. Peak mixer/encoder/code-exchange cost is 190,720 master clocks in the ordinary run and 190,652 in the conversion stress run. Voice 0 plays for 103 observed fields. The ordinary observer first sees an active envelope at field 3 after admission; this is not a source-event timing certification.

The inherited type-1 character-conversion view must end before S-CPU raw BW-RAM access. Parking the SA-1 alone does not do this. The fixture writes the shared CDMA end bit before clearing/copying audio state. A separate stress input explicitly activates the conversion registers before admission, and the complete PCM/BRR/DSP proof still passes. This follows the local Mesen SA-1 register authority (`Sa1.cpp`, `WriteSharedRegisters`, CDMA bit 7), and is a native emulator proof, not physical-console certification.

Zero prefill is rejected by DSP evidence even when native PCM, BRR, packet bytes and completion duration match: the retained measured run observes 1,345 DSP block identities instead of 1,188, with the first mismatch at block 112. An earlier zero-prefill trial also ended after only 10 active fields. These variant failures do not reject the successful one-packet path or the complete audio architecture. Screenshot, envelope duration and transport bytes alone would have missed the measured block failure.
